# Program Roadmap

A six-phase, roughly 30-week program. Each phase ends with a standalone repository that consumes the output of the previous phase.

| Phase | Weeks | Focus | Deliverable |
|---|---|---|---|
| 0. Foundations | 1-3 | RevOps fundamentals, Git and GitHub standards, HubSpot environment | This hub repository |
| 1. CRM Architecture | 4-7 | Object model, lifecycle stages, pipelines, custom objects, validation rules, permissions | Project 01: CRM architecture and ERD |
| 2. Data Foundations | 8-12 | SQL, PostgreSQL, star schema, Python and Pandas, data quality | Project 02: SQL analytics library on a seeded warehouse |
| 3. BI and Executive Dashboards | 13-16 | Power BI, DAX, KPI trees, executive storytelling | Project 03: Pipeline health dashboard |
| 4. Analytics and Forecasting | 17-21 | CAC, LTV, NRR, GRR, pipeline velocity, forecast accuracy, cohorts | Project 04: Revenue forecasting engine |
| 5. Automation and Integration | 22-25 | n8n, Zapier, HubSpot workflows, REST APIs, webhooks, Python | Project 05: Lifecycle automation platform |
| 6. Capstone | 26-30 | Integration of all previous work | Revenue intelligence platform |

## Principles

- **Real business impact.** Every project opens with a business problem, objective, pain points, stakeholders, constraints, risks, and expected ROI.
- **Nothing is isolated.** Dashboards read earlier data, automations call earlier systems, and decisions persist unless explicitly migrated.
- **Increasing difficulty.** No toy examples and no repeated projects.
- **Documentation is part of the product.** Business requirements, technical design, decision records, data dictionary, runbook, and lessons learned ship with the code.

## Weekly Rhythm

Five to eight hours per week: one theory session, one or two build sessions, one documentation and review session, and a short interview-style Q&A.
