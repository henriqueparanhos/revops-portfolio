## Repository Conventions

- **Hub and project repositories.** This repository is the hub. Each project has its own repository (see [ADR-0001](docs/decisions/ADR-0001-hub-and-project-repositories.md)).
- **Documentation first.** Every project ships with a business context, architecture, data dictionary, and lessons learned. See the [project README template](docs/templates/PROJECT_README_TEMPLATE.md).
- **Commits** follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `docs:`, `fix:`, `refactor:`, `test:`, `chore:`).
- **Branches:** `main` is always presentable. Work happens in short-lived `feat/`, `docs/`, and `fix/` branches merged by pull request.
- **Language:** all documentation, code, and commit messages are in English.
